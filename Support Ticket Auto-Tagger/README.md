# 🏷️ Support Ticket Auto-Tagger

Automatically tags support tickets using a lightweight sentence transformer (`all-MiniLM-L6-v2`) + cosine similarity.

### 🔍 What it does
- Takes user-entered support ticket text.
- Finds the most relevant tags from a predefined list.
- Runs fast — no GPU required.
- UI built with Streamlit.

---

### 🚀 How to Run

1. Clone this repo:

```bash
git clone https://github.com/umarsubhani369/SummerTak2.git
cd "SummerTak2/Support Ticket Auto-Tagger" ```

### Install dependencies:
```bash
pip install -r requirements.txt

### Run the app:
```bash
streamlit run app.py
